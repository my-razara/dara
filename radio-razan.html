🎙️ Studio Razan — halaman ini cuma kebuka lewat radio-razan.html?studio, Dara ga bakal liat.

1. Tap Rekam, bacain naskahnya, tap Stop.
2. Dengerin dulu, kalau kurang sreg rekam ulang.
3. Tap Simpan file, terus upload filenya ke folder audio/radio/ (sebelahan sama radio-razan.html).

Nama file harus persis: pagi, malam, kangen, ngambek, galau, bahagia — boleh .mp3 / .m4a / .webm. Biar pasti bisa diputer di semua HP (termasuk iPhone), paling aman .mp3 atau .m4a.

Kalau file suara buat satu siaran belum ada, siaran itu otomatis balik ke mode teks kayak biasa.
